# Лабораторная работа № 1. Консольный набор утилит

Проект содержит калькулятор арифметических выражений и конвертер величин. Программа запускается из терминала как Python-пакет `toolkit`.

## Возможности

### Калькулятор

- Целые и дробные числа.
- Операции сложения, вычитания, умножения и деления: `+`, `-`, `*`, `/`.
- Приоритет умножения и деления над сложением и вычитанием.
- Выполнение операций одинакового приоритета слева направо.
- Круглые скобки, в том числе вложенные.
- Унарные знаки `+` и `-` перед числом или выражением в скобках.
- Пробелы, табуляции и переводы строк между токенами.
- Проверка записи выражения и деления на ноль.

Калькулятор преобразует выражение в обратную польскую запись (ОПЗ), затем вычисляет результат с помощью стека.

### Конвертер

| Группа | Поддерживаемые единицы |
| --- | --- |
| Длина | `mm` — миллиметры, `cm` — сантиметры, `m` — метры, `km` — километры |
| Масса | `g` — граммы, `kg` — килограммы |
| Температура | `c` — градусы Цельсия, `f` — градусы Фаренгейта, `k` — кельвины |

Регистр единиц не учитывается: например, `CM` и `cm` обозначают одну единицу. Конвертация между разными группами запрещена. Температура ниже абсолютного нуля отклоняется: ниже −273,15 °C, −459,67 °F или 0 K.

Вычислительные функции возвращают результат типа `float`.

## Требования и установка

Требуется Python 3.12 или новее. Для тестов используется `pytest`, для проверки кода — `Ruff`.

Ниже приведены команды для Windows PowerShell. Открой терминал в корне репозитория `python-labs`, где находится папка `lab_01`.

Создай виртуальное окружение, если оно ещё не создано:

```powershell
python -m venv .venv
```

Активируй окружение и перейди в папку лабораторной:

```powershell
.\.venv\Scripts\Activate.ps1
cd lab_01
```

Установи пакет с зависимостями и инструмент проверки кода:

```powershell
python -m pip install -e .
python -m pip install ruff
```

Параметр `-e` устанавливает проект в режиме редактирования: изменения Python-файлов становятся доступны без повторной установки. `pytest` устанавливается вместе с зависимостями проекта из `pyproject.toml`.

Все дальнейшие команды выполняются из папки `lab_01` в активированном виртуальном окружении.

## Запуск

### Справка

```powershell
python -m toolkit --help
python -m toolkit calc --help
python -m toolkit convert --help
```

### Калькулятор

Выражение передаётся одним аргументом в кавычках:

```powershell
python -m toolkit calc "2 + 3 * 4"
```

Результат:

```text
14.0
```

Другие примеры:

| Команда | Результат |
| --- | --- |
| `python -m toolkit calc "(2 + 3) * 4"` | `20.0` |
| `python -m toolkit calc "-3+5"` | `2.0` |
| `python -m toolkit calc "-(2+3)"` | `-5.0` |
| `python -m toolkit calc "12.5 / 2"` | `6.25` |
| `python -m toolkit calc "2 - -3"` | `5.0` |
| `python -m toolkit calc "8 / 4 * 2"` | `4.0` |

Для выражения с начальным минусом также можно явно указать разделитель аргументов `--`:

```powershell
python -m toolkit calc -- "-3+5"
```

### Формат выражений

Дробная часть отделяется точкой. Допустимые числовые токены: `0`, `7`, `12`, `0.5`, `12.5`. Знак обрабатывается как отдельный токен.

Записи с ведущими нулями (`007`, `00.5`), без цифр с одной стороны точки (`.5`, `12.`), с десятичной запятой или в экспоненциальной форме (`1e3`) не поддерживаются.

Пробелы разрешены между токенами, но не внутри числа: `1 2` не считается числом `12`. Неявное умножение не поддерживается: вместо `2(3 + 4)` нужно написать `2 * (3 + 4)`.

Перед операндом допускается один унарный знак. Поэтому `2 - -3` корректно: первый минус означает вычитание, второй — знак числа. Выражения `--3` и `5++++4-3` отклоняются.

Вычисления выполняются с типом `float` без дополнительного округления. Например, результат `0.1 + 0.2` может отображаться как `0.30000000000000004` из-за двоичного представления дробных чисел.

### Конвертер

Общий формат команды:

```text
python -m toolkit convert VALUE --from UNIT --to UNIT
```

`VALUE` — исходное значение, `--from` — исходная единица, `--to` — целевая единица.

| Команда | Результат |
| --- | --- |
| `python -m toolkit convert 2 --from m --to cm` | `200.0` |
| `python -m toolkit convert 1500 --from mm --to m` | `1.5` |
| `python -m toolkit convert 2500 --from g --to kg` | `2.5` |
| `python -m toolkit convert 0 --from c --to f` | `32.0` |
| `python -m toolkit convert 20 --from c --to k` | `293.15` |
| `python -m toolkit convert 150 --from CM --to MM` | `1500.0` |

Программа выводит числовой результат без обозначения единицы измерения.

## Обработка ошибок

Проверяются пустое выражение, недопустимые токены, пропущенные операнды, некорректные сочетания операторов, расположение скобок и деление на ноль. Для конвертера проверяются числовой аргумент CLI, названия и совместимость единиц, а также нижняя граница температуры.

Примеры ошибочного ввода:

```powershell
python -m toolkit calc ""
python -m toolkit calc "2 +"
python -m toolkit calc "2 ** 3"
python -m toolkit calc "5 / 0"
python -m toolkit convert abc --from m --to cm
python -m toolkit convert 2 --from unknown --to m
python -m toolkit convert 2 --from m --to kg
python -m toolkit convert -1 --from k --to c
```

При успехе результат выводится в стандартный поток вывода (`stdout`), код завершения — `0`. При ошибке сообщение выводится в стандартный поток ошибок (`stderr`), код завершения — `2`. Справка также завершается с кодом `0`.

Код завершения последней команды в PowerShell можно посмотреть так:

```powershell
$LASTEXITCODE
```

Вычислительные функции используют встроенные исключения `ValueError` и `ZeroDivisionError`. Вывод сообщений пользователю выполняется на уровне CLI.

## Алгоритм калькулятора

Функция `calculate` последовательно вызывает четыре функции:

1. `tokenize` разбивает строку на числа, операторы и скобки.
2. `validate_tokens` проверяет допустимость токенов и порядок их расположения.
3. `to_rpn` преобразует выражение в обратную польскую запись с помощью стека операторов, учитывая приоритеты и скобки.
4. `evaluate_rpn` вычисляет результат с помощью стека чисел.

Например, выражение `8 - 2 * (3 + 1)` преобразуется в `8 2 3 1 + * -` и даёт результат `0.0`.

Унарные операции в ОПЗ обозначаются как `u+` и `u-`. Для бинарной операции из стека сначала извлекается правый операнд, затем левый. Это сохраняет правильный порядок при вычитании и делении.

Реализовано дополнительное задание: преобразование выражения в ОПЗ и вычисление стеком. Вычислительное ядро не использует `eval`, `exec`, `ast.literal_eval`, сторонние библиотеки разбора выражений, `input` или `print`.

## Тестирование и проверка кода

Запуск всех тестов:

```powershell
python -m pytest
```

Подробный вывод:

```powershell
python -m pytest -v
```

Запуск только тестов CLI:

```powershell
python -m pytest tests/test_cli.py
```

Тесты проверяют обычные вычисления, приоритеты, скобки, унарные знаки, преобразование в ОПЗ, конвертацию величин и обработку ошибок. Вычислительные функции проверяются прямыми вызовами, CLI — через `subprocess`.

Проверка кода с помощью Ruff:

```powershell
python -m ruff check .
```

Форматирование исходников и тестов:

```powershell
python -m ruff format src tests
```
